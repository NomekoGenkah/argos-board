No hay agentes a la vista

En otra terminal, lanza un agente a través del wrapper:

argos-board run -- claude

Arrastra la cabecera de una tarjeta para moverla y su borde o esquina para redimensionarla. Con el teclado, sobre una tarjeta: Mayúsculas y flechas cambian el tamaño; Control y flechas la mueven.

Emparejar este dispositivo

Desde la red, este dispositivo necesita un código de un solo uso. Aparece en la terminal donde corre argos-board serve (la primera vez) o se genera en el servidor con:

argos-board pair

Ingrésalo aquí. Caduca a los 5 minutos y se anula tras 5 intentos fallidos.

Escribir en los agentes

Al arrancar, argos-board serve imprime un enlace con un token:

Para escribir en los agentes desde la página, abre: http://localhost:8787/#k=…

Ábrelo una vez en este navegador; la página lo recuerda. Para quitarle el permiso a todos los navegadores, borra ~/.config/argos-board/control-token y reinicia el servidor.
